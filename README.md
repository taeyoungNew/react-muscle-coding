# 🧠 React 머슬코딩 (Custom Hooks Practice)

리액트 커스텀 훅 및 실무 아키텍처 패턴을 백지 상태에서 반복 구현하며 체화하는 레포지토리입니다.

## 📌 구현 목록

- [x] Level 1~2: `useInput`, `useTabs`
- [x] Level 3: `useToggle` (`as const` 튜플 타입, 함수형 업데이트)
- [x] Level 3: `useDebounce` (클린업 타이머 제어, 제네릭 추론)
- [x] Level 3: `useLocalStorage` (Lazy Initialization, 스토리지 동기화)

# 추천하는 머슬 코딩 3단계 루틴

## 1단계: 원리 파악 & 1차 완성 (이해 단계)

참고 자료나 가이드를 보더라도 전체 흐름과 타입 설계를 이해하면서 코드를 끝까지 완성합니다. (시간이 오래 걸려도 정상)

## 2단계: 다음 주제 진행 (전진)

한 훅에 너무 오래 머물지 않고 다음 커스텀 훅이나 과제로 넘어가 새로운 패턴을 접합니다.

## 3단계: 백지 재구현 (머슬 메모리 완성)

다음 날이나 주말에 레포지토리의 파일 내용을 싹 지우고, 아무것도 보지 않은 상태에서 10분 안에 쳐보는 시도를 합니다.

막히는 부분이 바로 본인이 '다 안다고 착각했던 빈틈'입니다. 그 부분만 살짝 확인하고 다시 닫은 뒤 끝까지 작성합니다.
